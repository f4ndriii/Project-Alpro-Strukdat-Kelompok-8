# Project-Alpro-Strukdat-Kelompok-8
Proyek akhir mata kuliah algoritma pemrograman dan struktur data.
Kelompok 8: Alfandri Triyandami, Adzan Daffa Karim, Mutiara Nur Syafiqa

“Simulator Kebun Pintar & Perawatan Tanaman Digital (Smart Garden System)”

•	OOP: Class Tanaman, Kebun, dan Perawatan 
•	Sorting: Mengurutkan tanaman berdasarkan umur, tinggi, atau kebutuhan air terbanyak 
•	Searching: Mencari nama tanaman atau jenis tanaman tertentu 
•	File Handler: Menyimpan data tanaman dan riwayat perawatan ke dalam file .txt agar dapat dibuka kembali 
•	Rekursif: Menghitung total kebutuhan air dan pupuk tanaman secara bertingkat berdasarkan jumlah tanaman dalam kebun 
•	List, Tuple, Set, Dictionary: List untuk daftar tanaman, Tuple untuk koordinat posisi tanaman, Set untuk jenis tanaman unik, dan Dictionary untuk detail perawatan tanaman 
•	Stack: Fitur “Undo” untuk membatalkan perubahan data tanaman terakhir 
•	Queue: Antrean jadwal penyiraman tanaman 
•	Single Linked List: Urutan jadwal perawatan tanaman harian 
•	Double Linked List: Navigasi riwayat pertumbuhan tanaman sebelumnya dan berikutnya 
•	Circular Linked List: Pergantian jadwal penyiraman otomatis yang terus berulang setiap hari 
•	Tree: Struktur kategori tanaman (Tanaman Hias > Bunga > Mawar) 
•	Graph: Hubungan antar area kebun atau jalur penyiraman tanaman 
•	Hash Table: Menyimpan ID unik tanaman untuk pencarian data yang cepat 

Fitur :
1.	Penyusunan Data Tanaman dan Kebun (OOP) 
2.	Database Tanaman dan Perawatan (List, Tuple, Set, Dictionary) 
3.	Penyimpanan Data Tanaman ke File (File Handler) 
4.	Pengurutan Tanaman Berdasarkan Umur atau Tinggi (Sorting) 
5.	Pencarian Nama atau Jenis Tanaman (Searching) 
6.	Penghitungan Total Kebutuhan Air dan Pupuk (Rekursif) 
7.	Fitur Pembatalan Perubahan Data / Undo (Stack) 
8.	Sistem Antrean Penyiraman Tanaman (Queue) 
9.	Jadwal Perawatan Tanaman Harian (Single Linked List) 
10.	Navigasi Riwayat Pertumbuhan Tanaman (Double Linked List) 
11.	Sistem Jadwal Penyiraman Berulang Otomatis (Circular Linked List) 
12.	Struktur Hierarki Jenis Tanaman (Tree) 
13.	Visualisasi Jalur Antar Area Kebun (Graph) 
14.	Sistem Pencarian ID Tanaman Cepat (Hash Table)
